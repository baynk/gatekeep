## Design lab

Design work for this project is staged and remembered in the design lab at `~/design-lab` (project `gatekeep`).
Every agent and tool that works here shares it, so use it instead of leaving mockups in a scratch folder.

- Before any visual or UI work, run `python3 ~/design-lab/tools/lab.py brief gatekeep` and follow what it says
  about what Ryan has liked and rejected.
- Stage each alternative you want judged, and record Ryan's reaction word for word. The steps are
  in `~/design-lab/LAB.md`.
- The lab's page is `~/design-lab/index.html`, also published at https://claude.ai/artifact/SH4mZXy99cNBsqXnXmWvhc.
